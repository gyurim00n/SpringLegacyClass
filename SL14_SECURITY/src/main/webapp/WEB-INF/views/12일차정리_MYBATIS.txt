 25. 꼭 기억해야 할 클래스와 메서드

Spring Security 공부에서는 아래 정도를 우선순위로 잡으시면 됩니다.

클래스/인터페이스   핵심 역할   중요 메서드
DelegatingFilterProxy   Servlet ↔ Spring 연결   doFilter()
FilterChainProxy   Security Filter Chain 실행   doFilter()
SecurityContextHolder   현재 인증정보 접근   getContext()
SecurityContext   Authentication 보관   getAuthentication()
Authentication   인증 사용자 정보   getPrincipal(), getAuthorities()
UsernamePasswordAuthenticationFilter   로그인 요청 처리   attemptAuthentication()
AuthenticationManager   인증 관리자   authenticate()
ProviderManager   Provider에게 인증 위임   authenticate()
AuthenticationProvider   실제 인증 수행   authenticate()
DaoAuthenticationProvider   DB 기반 인증   authenticate()
UserDetailsService   사용자 조회   loadUserByUsername()
UserDetails   사용자 정보   getUsername(), getPassword(), getAuthorities()
PasswordEncoder   비밀번호 검증   matches()
SecurityContextPersistenceFilter   SecurityContext 저장/복원   doFilter()
CsrfFilter   CSRF 검사   doFilterInternal()
ExceptionTranslationFilter   보안 예외 처리   doFilter()
FilterSecurityInterceptor   URL 접근 권한 검사
